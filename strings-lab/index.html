How this listening room works

Choose a phrase, press Play once, then adjust it and Replay. During Loop, edits enter on the next cycle. Pair mode starts both voices together; each keeps its own note lengths. Automatic ensemble scheduling comes later.

Humanise gently varies note lengths and strengths. Leave it off for repeatable comparisons. Dry removes the string reverb. Reverb tails continue during the rest; Stop fades the entire mix.

The lab uses a JavaScript port of the live instrument’s physical string model with extra bow controls. Sustained tone, short bows and tremolo still need your listening approval. The pad uses the existing instrument’s pad synthesis. The live performance page is unchanged.

Exports include all eight working phrases, saved versions, tags and notes. Save or export before clearing browser data. Imported settings replace this lab’s current collection only after confirmation.
